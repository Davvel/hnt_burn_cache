HNT Burn Cache v1.5.0

Policy:
- Every scheduled run executes a completely fresh Dune query.
- No previous JSON cache is used to build the new data.
- Cache includes today (partial), yesterday, and 30 days ending at T-2.
- Mobile app must display only dates <= today - 2 days.
- With HISTORY_DAYS=30 the cache can contain up to 32 daily rows.
